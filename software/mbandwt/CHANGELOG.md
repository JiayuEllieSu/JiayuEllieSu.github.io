# Changelog

## 0.1.0 (initial public source release)

- M-channel FIR analysis and synthesis filter banks, polyphase diagnostics.
- One-level and multilevel 1D transforms with recorded inverse bookkeeping.
- Periodic and expansive finite-extension boundary modes.
- Basic orthonormal and paraunitary filter-bank constructions.
- Automated round-trip, energy, and external regression tests.
- Public-release cleanup: documentation, packaging metadata, parameter
  validation, and regression tests.

This is an early development release. API stability is not guaranteed.
